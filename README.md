# PyBomjoChat

Локальный веб-чат для моделей LiteRT-LM. Модели берутся из папки `models`, история диалогов сохраняется в `.chats.json`, а ответ модели и работа её инструментов отображаются по мере поступления событий.

## Запуск

Поместите файлы моделей с расширением `.litertlm` в `models`, затем запустите из папки проекта:

```powershell
.\.venv\Scripts\python.exe main.py
```

Откройте <http://127.0.0.1:8000>. Чтобы сменить модель, введите `/model` и выберите её из списка либо используйте `/model имя-модели`.

Модель может вызывать веб-поиск DuckDuckGo и инструменты чтения/записи файлов внутри папки проекта. Веб-поиск требует подключения к интернету. Сервер по умолчанию доступен только на этом компьютере.

## Терминальный интерфейс

Запустите из папки проекта:

```powershell
.\.venv\Scripts\python.exe cli.py
```

CLI использует ту же историю чатов и каталог моделей, что и веб-интерфейс. Ответ выводится потоком, а вызовы инструментов показываются в терминале. Команды: `/new`, `/chats`, `/open <номер|id>`, `/model [номер|имя]`, `/delete`, `/help` и `/exit`. Обычный текст отправляется модели; веб-поиск доступен модели как инструмент.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
```
